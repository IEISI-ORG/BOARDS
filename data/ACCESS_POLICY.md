# Source access register

This project uses only sources that automated agents may access. For every source we check its terms of
use (AUP / terms of service) and `robots.txt`. If the terms prohibit automated or agent access, we record
that and stop using the source automatically. If we find no such prohibition, we record that we found
none and use the source. Checked 2026-10-01 unless stated.
